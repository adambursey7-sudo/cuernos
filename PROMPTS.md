# Prompts de la app

Se pueden probar ya, a mano, pegándolos en Claude con una ficha de `sistemas/` delante. Lo que va entre corchetes se cambia en cada uso.

---

## 1. Adaptar un sistema a un equipo

```
Eres el ayudante de un entrenador de baloncesto de formación.
Te doy la ficha de un sistema y los datos del equipo. Adáptalo.

Ficha del sistema:
[pegar la ficha de sistemas/, por ejemplo cuernos.md]

Equipo:
- Categoría y nivel: [cadete femenino, nivel medio]
- Puntos fuertes: [buenas pasadoras, rápidas al contraataque]
- Puntos débiles: [poco tiro de tres, interiores bajas]
- Jugadoras disponibles: [10]

Devuélveme:
1. Qué variante del sistema les conviene y por qué (2 o 3 frases).
2. Colocación inicial y los pasos del sistema, uno por línea, con números de jugadora (1 a 5).
3. Las 2 lecturas que deben aprender primero y las que se dejan para más adelante.
4. Errores típicos de esta edad con este sistema y cómo corregirlos.
No inventes movimientos que no estén en la ficha. Si algo no encaja con el nivel, dilo.
```

## 2. Ejercicios de progresión para un sistema

```
Con este sistema ya adaptado:
[pegar la respuesta del prompt 1]

Prepara una progresión de ejercicios para enseñarlo en [3] sesiones:
- De menos a más: 2x0, 3x0, 2x2, 3x3, 5x0 y 5x5.
- Para cada ejercicio: nombre corto, objetivo, organización (jugadoras, canastas, balones, conos), desarrollo en 3 o 4 pasos, una variante más fácil y otra más difícil, y en qué fijarse al corregir.
- Duración de cada ejercicio en minutos.
Nivel: [cadete femenino, nivel medio]. Pista: [una pista entera, 2 canastas laterales].
```

## 3. Montar una sesión

```
Monta una sesión de [90] minutos para [cadete femenino], [martes], con [10] jugadoras y [2] entrenadores.
Objetivo principal: [cuernos: bloqueo directo y lectura del pívot que continúa].
Objetivo secundario: [defensa del bloqueo directo].
Usa estos ejercicios si encajan: [pegar ejercicios del prompt 2].

Estructura: calentamiento con balón, parte principal, juego final y vuelta a la calma.
Tabla con: minuto de inicio, ejercicio, duración, organización, material y quién lo dirige.
Al final, 3 frases para la charla con las jugadoras, en su lenguaje.
```

## 4. Ficha nueva para la base de sistemas

```
Escribe la ficha del sistema [nombre, por ejemplo «flex»] siguiendo exactamente el formato de esta ficha de ejemplo:
[pegar sistemas/cuernos.md]

Solo lo que sea estándar y reconocido en el baloncesto. Marca con «REVISAR» cualquier cosa de la que no estés seguro.
La revisa un entrenador antes de entrar en la base.
```
